# Mini-Dify UI 设计文档

> 前端技术栈：Next.js 14+ (App Router) + shadcn/ui + Tailwind CSS

---

## 1. 页面路由结构

| 路由 | 页面 | 说明 |
|------|------|------|
| `/login` | 登录页 | GitHub/Google OAuth 登录 |
| `/` | Dashboard 首页 | 自动重定向到 `/models` |
| `/models` | 模型管理 | 供应商列表、添加供应商、模型详情 |
| `/prompts` | Prompt 列表 | Prompt 模板列表、搜索、筛选 |
| `/prompts/[id]` | Prompt 编辑器 | 左侧编辑 + 右侧测试（分栏布局） |
| `/knowledge` | 知识库列表 | 知识库卡片列表、创建 |
| `/knowledge/[id]` | 知识库详情 | 文档列表、上传、检索测试 |
| `/agents` | Agent 列表 | Agent 卡片列表、创建 |
| `/agents/[id]` | Agent 配置 | 基本信息 + 工具配置 + Playground |
| `/workflows` | 工作流列表 | 工作流卡片列表、创建 |
| `/workflows/[id]` | 工作流编辑器 | React Flow 画布 |
| `/apps` | 应用列表 | 应用卡片列表、创建 |
| `/apps/[id]` | 应用配置 | 类型配置 + API Key 管理 + 预览 |
| `/monitoring` | 监控面板 | 图表 + 日志列表 |

### 侧边栏状态

- **展开态** 宽度：`w-64`（256px），显示图标 + 文字
- **收缩态** 宽度：`w-16`（64px），仅显示图标，hover 显示 Tooltip
- 底部包含收缩/展开按钮和用户头像菜单

### TopBar

- 左侧：Breadcrumb 面包屑导航（自动根据路由生成）
- 右侧：页面级操作按钮（如「新建」「保存」等），根据页面动态变化

## 6. 交互说明

### 6.1 流式输出动画

```
实现方式：Server-Sent Events (SSE) + StreamingText 组件

流程：
1. 用户发送消息 → 显示 loading 动画（三个跳动的点）
2. 收到第一个 token → 隐藏 loading，开始逐字显示
3. 每收到一个 token → 追加到文本末尾，末尾显示闪烁光标 ▌
4. 流结束 → 隐藏光标，显示完整文本
5. 错误时 → 显示红色错误提示，可重试

光标样式：
  .streaming-cursor {
    display: inline-block;
    width: 2px;
    height: 1em;
    background: currentColor;
    animation: blink 1s step-end infinite;
  }
```

### 6.2 工作流节点拖拽与连线

```
基于 React Flow 实现：

交互流程：
1. 从左侧节点面板拖拽节点到画布 → 创建新节点
2. 从节点的输出端口（右侧圆点）拖拽到另一节点的输入端口（左侧圆点） → 创建连线
3. 点击节点 → 右侧显示属性面板
4. 双击节点 → 编辑节点名称
5. 按 Delete 键 → 删除选中的节点或连线（弹确认框）
6. 滚轮缩放 → 画布缩放
7. 拖拽空白区域 → 画布平移

视觉反馈：
- 拖拽时：节点半透明跟随鼠标
- 连线时：显示虚线引导线
- 连接成功：虚线变实线，端口高亮
- 无效连接：端口显示红色，连线消失
- 运行中：节点边框流光动画，已完成的节点显示绿色勾
```

### 6.3 文件上传进度

```
交互流程：
1. 拖拽文件到上传区域 → 区域高亮（虚线边框变蓝色）
2. 释放文件 → 显示文件列表，每个文件显示进度条
3. 上传中 → 进度条动画（百分比 + 进度条）
4. 上传完成 → 进度条变绿色 + 勾号
5. 上传失败 → 进度条变红色 + 错误原因 + 重试按钮

文件验证：
- 文件类型不支持 → Toast 提示 "不支持的文件类型"
- 文件过大 → Toast 提示 "文件大小超过限制 (最大 10MB)"
```

### 6.4 Toast 通知

```
使用 shadcn/ui 的 Sonner (toast) 组件：

位置：屏幕右下角
类型：
  - success：绿色图标，操作成功（如 "保存成功"、"删除成功"）
  - error：红色图标，操作失败（如 "保存失败：网络错误"）
  - warning：黄色图标，警告提示
  - info：蓝色图标，信息提示
  - loading：旋转图标，处理中（如 "正在上传..."）

自动消失：3 秒后自动消失（error 类型需手动关闭）
堆叠：最多同时显示 3 条，超出时旧消息向上堆叠
```

### 6.5 确认对话框

```
使用 shadcn/ui 的 AlertDialog 组件：

触发场景：
- 删除操作（模型、Prompt、知识库、Agent、工作流、应用）
- 取消编辑（有未保存的修改时）
- 重新生成 API Key

对话框结构：
┌──────────────────────────────────┐
│  ⚠️  确认删除                    │
├──────────────────────────────────┤
│                                  │
│  确定要删除 "智能客服助手" 吗？  │
│  此操作不可撤销。                │
│                                  │
│            [取消]  [确认删除]    │
└──────────────────────────────────┘

- [确认删除] 按钮使用 destructive 样式（红色）
- 支持键盘操作：Escape 取消，Enter 确认
```
